PORTFÓLIO DE TI

1. Edite o index.html:
- Troque "Seu Nome" pelo seu nome.
- Troque o e-mail.
- Coloque seus links do LinkedIn e GitHub.
- Na experiência, coloque suas atividades reais de Help Desk.

2. Mantenha os nomes:
index.html
style.css

3. No GitHub:
- Abra seu repositório SEUNOME.github.io.
- Add file > Upload files.
- Envie index.html e style.css.
- Faça o commit.
- Vá em Settings > Pages.
- Source: Deploy from a branch.
- Branch: main e pasta / (root).
- Salve.

Depois, o site ficará em:
https://SEUNOME.github.io

Antes de publicar, substitua os campos de exemplo pelos seus dados reais.
